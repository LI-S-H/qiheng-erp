# 架构资料

本目录按当前代码和已提供的数据库结构组织项目架构，面向需要理解项目组成、业务规则和 AI 模块的开发者。建议先阅读总体架构，再按关注的业务或 AI 机制进入专题；数据库字段和索引由数据库资料维护。

- [总体架构](overview.md)：前后端职责、模块协作、基础服务、典型调用链和验证视角。
- [传统业务架构](business.md)：基础资料、订单状态、库存预占、分批履约、退货约束和供应商评分。
- [AI 架构](ai.md)：会话与按轮分页、SQL 取数约束、数据完整性、业务技能、采购草稿确认与写操作、分析、报告、上下文压缩与经验。
- [数据库业务关系](../database/relations.md)：表之间的逻辑关联和边界。
- [当前代码状态](../current-status.md)：已发现的代码入口、限制与待验证项。
- [库存健康与补货建议规划](../plans/inventory-replenishment.md)：独立业务能力的后续规划，以及与已有 AI 技能的区别。

上述说明依据代码静态整理，流程图概括主要路径；实际功能启用、授权范围和业务结果仍需按测试环境验证。文档中的示例只用于解释机制，具体状态、校验和数据口径以当前服务代码为准。
