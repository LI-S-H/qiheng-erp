# 当前代码状态与验证边界

本页依据当前仓库静态检查和隔离数据库测试整理；代码入口存在不代表目标环境已经完成业务验收。

- **传统业务**：系统权限、商品、供应商、客户、采购、销售、仓储、库存与退货均有前后端入口，见[业务架构](architecture/business.md)。
- **AI**：存在主智能体、受控 SQL、分析、报告、上下文压缩及经验提取与检索相关代码，启用条件和安全边界见 [AI 架构](architecture/ai.md)；模型效果和目标环境数据权限需要验证。
- **AI 业务技能**：代码支持外部技能目录、主智能体与分析智能体分组、按需读取和定时刷新。仓库已有需求预测、库存健康、库存策略、补货、采购执行和供应商选择技能；具体清单可能继续变化。技能是指导规则，不代表所有场景已通过模型、数据与工具的端到端验收，见[技能机制](architecture/ai.md#业务技能加载与扩展)。
- **供应商评分**：存在计算、消息处理和定时校正；目标环境需要核对任务开关和实际运行结果。
- **数据库**：按照提供的结构和系统测试数据生成[空测试库初始化文件](database/init/README.md)，已在隔离库导入并通过模拟数据检查；登录、权限与完整业务接口仍需逐项验证。
- **未确认范围**：本次静态检查未确认采购和销售按部门实施数据范围隔离；是否需要库存盘点、跨仓调拨、应收应付及发票结算，应按产品范围确认，不以未发现入口推断所有相关代码不存在。

变化时记录对应版本、配置、测试结果及尚未验证的范围。测试计划和入口见[测试资料](testing/README.md)。
