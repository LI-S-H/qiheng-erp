# 模拟数据

[demo-data-bundle.zip](demo-data-bundle.zip) 包含模拟数据 SQL、36 项规则检查、Redis 编号序列同步脚本和使用说明。数据仅供测试和演示，联系人、电话、地址和交易均为虚构数据。

## 2026-11-22 生成器 v2

新增 [generator](generator/README.md)，可重复生成一套分布更接近真实业务的数据。与 2026-11-20 的包相比：

- 供应商不再是每商品恰好一家：约 28% 商品有第二或第三供应商，备选供应商的价格、交期、质量分档有差异。
- 采购单和销售单约一半为多行明细，状态覆盖草稿、待审核、在途、部分入库/出库、取消，并有真实逾期到货。
- 供应商评分由采购事实反算，交付分 6529–10000、综合分 8632–9947，不再全部是满分。
- 库存按需求驱动模拟，期末存在零库存、低于安全库存、积压和跨仓调拨样本，锁定库存与未完成单据一致。
- 主数据名称按真实业务形态生成，不再使用"演示区域仓 01""华源供应链 001 号"这类编号名称。

验证状态：已在隔离库 `erp_demo_v2` 导入并通过 86 项业务规则检查；后端真实接口验证通过采购单提交/审核/入库确认、销售单提交/审核/出库确认和退货提交。当前开发库 `erp` 尚未替换，待确认后再切换。

生成、导入和检查方式见 [generator/README.md](generator/README.md)。

## 2026-11-20 数据修订

- 原有 102 个扁平分类已整理为 22 个上级和 104 个下级分类，1,560 个模拟商品挂载下级分类。商品列表展示挂载分类的名称；上级分类筛选包括其下级商品。
- 修正了原始 FoodMart 数据中 10 件洗衣及洗碗机清洁用品的分类；200 个客户、200 个供应商和 5 个仓库补充了模拟联系人、联系电话和地址。
- 目标库中有唯一同名启用上级时复用，包括非顶级上级；同级下已有唯一同名启用下级也会复用。存在重名歧义时导入停止，需先人工核对。
- 已在隔离 MySQL 与 Redis 中导入并通过 36 项检查；另验证了复用已有非顶级上级、重复上级时报错及事务回滚，并通过本地后端接口读取商品、分类及联系信息。此检查不能证明每条数据均由业务服务逐单产生。

本包适用于与包内注明版本兼容、尚未导入本批数据的测试库，不支持重复导入或原地修复旧版模拟数据。已在根据实际结构建立的隔离库中完成导入并通过 36 项检查。供应商评分为既有任务计算的快照，导入后应按包内说明重新校正。

## 2026-11-22 金额口径变更

`product.reference_purchase_price` 和 `reference_sale_price` 已由 `decimal(18,2)` 元改为 `bigint` 分，与交易金额统一。**包内 `demo_data.sql` 是 2026-11-20 生成的旧版，参考价为元，不能导入新结构**，否则价格会小 100 倍。请使用 [generator](generator/README.md) 重新生成，输出中的参考价已按分写入。
