# 模拟数据

[demo-data-bundle.zip](demo-data-bundle.zip) 包含模拟数据 SQL、36 项规则检查、Redis 编号序列同步脚本和使用说明。数据仅供测试和演示，联系人、电话、地址和交易均为虚构数据。

## 2026-11-20 数据修订

- 原有 102 个扁平分类已整理为 22 个上级和 104 个下级分类，1,560 个模拟商品挂载下级分类。商品列表展示挂载分类的名称；上级分类筛选包括其下级商品。
- 修正了原始 FoodMart 数据中 10 件洗衣及洗碗机清洁用品的分类；200 个客户、200 个供应商和 5 个仓库补充了模拟联系人、联系电话和地址。
- 目标库中有唯一同名启用上级时复用，包括非顶级上级；同级下已有唯一同名启用下级也会复用。存在重名歧义时导入停止，需先人工核对。
- 已在隔离 MySQL 与 Redis 中导入并通过 36 项检查；另验证了复用已有非顶级上级、重复上级时报错及事务回滚，并通过本地后端接口读取商品、分类及联系信息。此检查不能证明每条数据均由业务服务逐单产生。

本包适用于与包内注明版本兼容、尚未导入本批数据的测试库，不支持重复导入或原地修复旧版模拟数据。已在根据实际结构建立的隔离库中完成导入并通过 36 项检查。供应商评分为既有任务计算的快照，导入后应按包内说明重新校正。
