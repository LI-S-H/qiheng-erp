# 云仓 ERP 简约外观预览

本轮以用户明确认可的 `2026-10-16-agent-desktop` 演示为视觉基准，停止上一轮的三套生成图探索。原演示及生产前端没有修改。

## 打开

```powershell
node docs/design/2026-10-18-minimal/serve.cjs
```

[采购订单预览](http://127.0.0.1:5190/docs/design/2026-10-18-minimal/#purchase) · [库存预览](http://127.0.0.1:5190/docs/design/2026-10-18-minimal/#stock)

这是独立的 HTML/CSS/JS 预览。直接引用原演示 `prototype.css`、Lucide 图标与项目已有字体和 Logo；`minimal.css` 仅适配现有业务字段，不另造一套视觉体系。

## 简约依据

- 保留原演示浅灰背景、白色矩形容器、细边框、常规字重、稳定间距与留白。
- 状态使用原演示的小型填充标签，取消新增的大图形、阶段圆环和装饰图标。
- 筛选与表格按原演示的简单结构组织；不以“扁平化”为由强行合并所有区域。
- 汇总保留标签、值和本页口径，改成轻量文字；不使用大数字卡片。
- 按钮和行操作沿用原演示家族，不做组件展示区、设计画板或额外视觉说明面板。
- 保留当前 ERP 的完整导航和字段，故信息密度高于原演示；表格容器滚动保证内容完整，操作列可见。

## 内容来源与边界

`capture-data.cjs` 通过独立 Mock 开发服务导出当前项目的 11 条采购记录、20 条库存记录至 `data.json`，并保存真实页面文字和表格快照 `source-pages.json`。日期、金额、名称和编码均来自该 Mock；无真实业务数据。供应商名与编码、日期与时间调整主次排版，信息未删除。

采购保留 4 个筛选与 9 列、原状态和副说明、4 项本页汇总、查询/重置/刷新/分页/每页条数及原操作入口。库存保留 5 个筛选、风险预设、10 列、状态和 4 项本页汇总。库存延续“不统计总数”的分页外观。

筛选与分页在本地 Mock 数据中演示。采购“处理/查看”打开只读预览；新增和其他业务菜单明确提示本轮预览边界，不执行创建、审核、入库或任何真实业务写入。其他业务页面尚未制作预览。

## 验证

运行 `node docs/design/2026-10-18-minimal/qa.cjs`，需要本地 Edge 与现有 Playwright 依赖。

- 采购初始页 9 列、10 条记录、汇总 1/2/3/4；逐项比对原表格文字，允许日期时间的纯排版换行。
- 采购查询、重置、翻页和只读弹窗。
- 库存 10 列、初始汇总 4/9/4/5、产品编码查询及风险预设。
- 1115px、390px 宽度无外层横向溢出，保留表格内部滚动；移动导航打开、Esc 关闭。
- 浏览器无页面脚本错误。

截图：`reference-purchase.png`、`purchase-1440.png`、`stock-1440.png`、`purchase-1115.png`、`purchase-390.png`；机器结果见 `qa-results.json`。

本轮只编辑 `docs/design/` 的独立预览及说明，未修改 `erp-web/`、现行规范和接口契约。生产落地前仍需执行项目强制前端预检、规范同步、契约检查、构建与对应业务浏览器验证。
