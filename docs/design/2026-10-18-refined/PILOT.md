# 采购订单正式前端试点

用户认可精修预览后，授权先替换一个真实页面，并补充要求统一下拉、轻柔聚焦、新增与详情弹窗、页面切换动效、固定列和滚动。

采购、销售与仓储模块已获得用户认可，现已逐页完成[产品中心与系统权限六页迁移](./PRODUCT-SYSTEM-MODULES.md)。历史记录见[仓储模块](./WAREHOUSE-MODULE.md)、[销售模块](./SALES-MODULE.md)、[供货产品](./SUPPLIER-PRODUCTS-PILOT.md)、[供应商管理](./SUPPLIERS-PILOT.md)与[采购退回](./PURCHASE-RETURNS-PILOT.md)。

本页记录正式 Vue 页面 `/purchase/orders` 的实现。浅色导航和页面主题目前在采购四页、销售三页、仓储五页、产品中心两页、系统权限四页、[智能经营助手](../2026-10-19-ai-assistant-pilot/README.md)及[工作台](../2026-10-19-dashboard-pilot/README.md)共二十条路由启用。沿用现有 shadcn-vue / Reka UI 组件；供应商、仓库和产品仍由原远程搜索组件处理，不用原生 select 替代。

## 改动

- 单条四格本页汇总、浅底筛选、统一按钮、状态单标签，以及稳定的字体和对齐。
- 采购列表、新增明细和详情表格的表头、数据单元格全部居中；表头与主数据同为14px，表头500字重、正文400字重。供应商限宽文字块也左右居中，金额取消旧右对齐和单边留白。浏览器同时检查计算样式与列表文字真实边界的中心位置。
- 下拉触发框、搜索框、菜单、选中态、悬停、键盘焦点统一；普通聚焦为低透明度柔光，错误态保留红边。
- 用户进一步反馈辉光鲜艳、弹窗不够贴合页面后，聚焦改为中性灰蓝细边与单层 3% 极淡柔光，移除外扩蓝色模糊；弹窗遮罩降为 22% 中性色且不模糊背景。详情改为连续白底分区与细分隔，弱化多层卡片感；新增表单使用与页面汇总一致的浅灰表面。该轮仅修改 CSS，原文、字段、履约数值、进度、明细、流程记录与操作均保持。
- 新增、编辑、详情、二次确认和日期选择采用同一主题，保持原数据、校验、提交和审批流程。
- 单号与操作列左右固定，表头纵向固定，不透明背景配轻分隔；每页10条完整展开，20/50条才限制表格内部纵向滚动，分页始终可通过主工作区访问。见[三页分页高度修复](./PAGINATION-SCROLL.md)。
- 列宽按用户最新截图改为实际文字测量：字体就绪后用 Range 框住 Text 节点，读取真实排印字宽，包含真实字距与等宽数字；不读取整块 div 的盒宽。按每列最长表头或文字加上真实控件/单元格内边距生成显式 colgroup，采用固定布局避免浏览器二次分配。双行取较长一行，名称上限240px、单号180px；缓存仅本页面生命周期生效、只增不缩以减少翻页跳动。页面保持主工作区满宽，只保留常规32/40px内边距；宽屏剩余空间在真实字宽基数上均匀分给各列，禁止由表格自然宽度收窄整页。此前单列兜底和原生auto方案均已废弃。九列、窄屏横滚、首尾固定列、表头和分页保留。
- 根据导航字号偏小的反馈，一级菜单调整为 15px、二级菜单为 14px，均不小于业务正文 14px；保留菜单行高、层级与切换动效。
- 根据用户最新“表格文字可以大一点”的要求，主文字、单号与日期恢复14px/22px、400字重；辅助文字12px/18px，保持64px记录行。导航15/14px、筛选和弹窗14px不变。此前13px方案作为历史尝试结束，不再作为当前规则。
- 铃铛采用18px深灰图标、36px点击区，默认透明无边框，仅悬停、键盘聚焦或打开时显示浅底；数字明确白字蓝底、10px/600、高18px并以白边分隔。通知数量、零值隐藏、99+和待办弹层均保留。
- 保留原页面切换动效，复用共享列表加载层和提交锁；二次确认底层详情仍进入 inert。
- `MainLayout.vue` 本轮只添加主题样式导入与采购路由条件类；该文件原有 AI 权限变更属于工作区此前已有修改，保持原样。

未修改业务 API、DTO、Mock 记录、状态机或其它页面的默认组件外观。共享远程选择器仅增加当前选项的 `aria-current`，其选中样式由采购主题控制。

[打开实际采购前端](http://127.0.0.1:5192/purchase/orders)。本机试点服务使用项目 Mock 数据，账号 `admin`、密码 `123456`；新增和编辑只影响本次 Mock 会话。正式服务启动时会按原环境连接后端，采购新主题同样生效。

$env:VITE_USE_MOCK_API='true'
