# 工作台与智能助手设计预览

本目录是独立可审阅画布，不直接替换业务页面。真实助手现已[单独完成风格落地](../2026-10-19-ai-assistant-pilot/README.md)，可打开[本机实际页面](http://127.0.0.1:9071/ai/assistant)；工作台仍待用户审阅预览。本目录助手继续作为设计对照。设计沿用已确认的浅色满宽布局、柔和焦点、简洁组件与舒适字号，使用项目已有 Lucide 图标。

## 打开方式

直接用浏览器打开同目录 `preview.html`，无需启动服务。此单文件内嵌样式、脚本、图标、标志和对照截图，可以离线查看。顶部切换工作台/智能助手；助手右上角可切换计划、欢迎、补充条件、生成中、失败状态。所有数据为本地示例，不发送业务请求。业务跳转仍指向原本机预览服务5192，服务未启动时这些目标页无法打开。

本机新建HTTP监听返回系统 `EACCES`，因此交付不依赖5193服务；不要将该端口当作可用入口。

## 工作台方案

第三版在第二版布局基础上提高色彩辨识：销售用蓝色、库存健康用青色、风险用琥珀色、异常用柔和红色；指标采用小面积底色、侧线和图标，主要卡面仍为白色。趋势曲线、合计数字、环图、阶段刻度和商品排行同步加强，既避免过淡，也不使用辉光或大面积饱和渐变。保留负毛利、单位、比较基准与状态语义。

业务待办使用分类图标与数量标记。详情改为“左侧八类切换 → 分类与优先级 → 数量/当前状态/处理方式 → 业务记录 → 原处理指引”，单据保留来源、业务对象、金额、等待时长；库存保留产品编码、仓库、单位、可用/安全/建议补货数量；系统保留异常编号、来源、类型、等级、状态和发生时间。各类按原数据展示，不补造处理历史、负责人、虚假进度或原因。订单和仓库单据仍只在对应业务页处理；系统异常仅查看。

参考 [Ant Design 工作台设计规范](https://ant.design/docs/spec/research-workbench/) 的高频信息优先、关键路径和集中待办原则，以及 [Arco Design 色彩工具](https://arco.design/palette/list) 的分级色彩思路。只借鉴层级与语义色，不引入额外组件库，也不改变现有统计口径与接口。

趋势曲线增加柔和面积、逐线绘制、悬停参考线与数据点；库存分布改为四状态环图，正常13、低库存7、无可用2、零库存0保持不变；阶段与排行刻度仍直接来自原展示数值。卡片分批轻入场、下方内容首次滚入时显现，已读内容不重复隐藏。无持续闪烁、辉光或循环装饰。图表按实际像素重新投影，缩窄时字体不随SVG被挤扁。

| 原能力 | 画布与后续落地约束 |
| --- | --- |
| 本月销售额、毛利、待处理订单、风险SKU | 四项均保留，真实值、权限、同比环比和缺失基准沿用原响应 |
| 7/15/30日趋势 | 周期切换、悬停/键盘提示、数值表、负值零线保留；不改变统计口径 |
| 八类待办 | 保留列表和完整详情；订单来源/状态/等待时长、库存单位/安全库存/建议补货、异常类型/发生时间可在详情查看 |
| 受控操作 | 仅原有可操作业务显示“前往完成”；系统追踪异常只查看；入出库使用 `PENDING_CONFIRM`，保留status/from映射 |
| 库存状态 | 保留仓库选择、四种库存分布、风险清单与完整详情；仓库范围与跳转ID对应 |
| 订单阶段 | 采购与销售分开，原统计期间和阶段计数保留 |
| 商品与供应商 | 首页前五及完整明细均保留，保留产品编码、净销量、可用库存、交付/质量评分和平均到货天数 |
| 加载与异常 | 画布演示刷新、暂无权限、空态和保留旧数据提示；正式实现继续复用原请求与权限分支 |

后续仍使用 `GET /dashboard/overview`、`GET /dashboard/inventory-status?warehouseId` 与原仓库列表接口。页面字段直接绑定原组件/响应；画布中的示例数字不回写项目Mock或生产数据。

## 智能助手方案

左侧会话、中间对话、右侧计划；欢迎态保持简洁，避免夸张大图标、辉光和漂浮输入卡。正文14px，计划说明13px；输入区固定在对话底部，面板独立滚动。窄屏采用会话抽屉和计划覆盖面板。

第二版将消息跳转条置于**对话区左侧中部**，按照真实用户提问轮次生成；悬停或键盘聚焦显示提问预览，点击/Enter平滑定位，当前项随滚动更新。正文预留独立窄轨，手机同样不遮字。新建会话改为书写图标、柔和描边和轻微悬停反馈，业务行为不变。

| 原能力 | 画布与后续落地约束 |
| --- | --- |
| 会话管理 | 新建、日期分组、分组展开/收起、切换、重命名、删除确认、较早消息与草稿均保留 |
| 消息 | 用户/助手、时间、TEXT/CLARIFICATION/PLAN/ERROR分支，消息定位与进度明细保留；历史澄清正式实现继续只读 |
| 澄清 | 单一底部“确认并继续”；自定义范围空值会阻止提交，原必填、单选/多选及校验由真实契约驱动 |
| 输入 | Enter发送、Shift+Enter换行、输入法组合保护、10000字限制、忙碌态禁发 |
| 计划 | 标题、目标、SQL_QUERY/PYTHON步骤、计划空态与失败重读保留；明确当前只生成计划，尚未执行查询或Python代码 |
| 面板 | 会话200–320px、计划280–416px，鼠标/键盘调宽与本地保存，收起/展开，手机抽屉和计划面板 |

后续继续调用原 `GET /ai/assistant/overview`、会话创建/分页读取/修改/删除、消息分页，以及 `POST /ai/graph/stream`、`POST /ai/graph/resume/stream`、原会话进度流。请求参数、流事件、threadId/pauseId/answer及已有store保持。画布不新增执行分析、报告或调度入口。

## 动效与验证

画布保留页切换淡入淡出、趋势切换、库存刷新、面板宽度过渡、消息平滑定位及850ms轻提示，支持 `prefers-reduced-motion`。落地时继续复用 MainLayout 页面加载、原列表/图表/待办过渡及助手现有面板和消息动效，避免直接用画布脚本替换业务实现。
