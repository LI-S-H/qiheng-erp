# 页面美化提交范围与验证

本轮分为四批：共享主题与字体、业务列表与表单、工作台、助手视觉资产及设计验收资料。采购、销售、仓储、产品和权限页面采用统一字体、实际字宽、柔和焦点、下拉及弹窗、分页与局部加载；工作台包含最终认可的评分列位置和待办整行悬停。

## 与现有业务改动的边界

本轮不提交后端、数据库、OpenAPI、AI权限迁移或Graph业务改写，也不改变原有后端暂存区。混合文件按代码块拆分：MainLayout保留旧权限条件，仅纳入主题与通知视觉；package.json仅增加字体依赖；角色API仅纳入列表局部加载配置。

助手主页面、输入组件与新会话组件混有此前的旧聊天到Graph迁移，无法将整文件归为外观修改。此次仅提交独立的 `ai-pilot.css` 及样式导入，相关混合实现仍留在工作区。**单独检出本次提交不会得到尚未提交的Graph版助手完整界面**；独立样式会在该业务实现后续纳入时复用，不能把本轮提交描述为Graph功能交付。
