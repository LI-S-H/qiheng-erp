# 接口开发规范

接口契约位于 [OpenAPI](../api/erp-openapi.yaml)，退货设计见[退货接口说明](../api/return-module.md)。接口实际行为以当前 Controller、请求/响应类型、权限和测试为准；契约与实现存在差异时先核对并同步修正。

- API 修改需要说明请求、响应、状态码、权限、字段类型及兼容影响；分页、筛选和状态枚举要和服务端实现一致。
- 登录后的前端请求使用登录响应提供的令牌名称；不要在文档或测试结果中记录实际令牌。
- 在 `erp-web/` 可执行 `npm run check:openapi`。脚本链检查接口契约、当前初始化结构与对应文档，具体结果以运行输出为准，不应把未运行的检查当作已经通过。
- 生产 OpenAPI 与示例不得包含实际账号、密钥、个人联系方式或真实业务记录。
