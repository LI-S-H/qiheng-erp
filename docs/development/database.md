# 数据库开发规范

- 变更前核对[数据库结构说明](../database/schema/README.md)、实际 MySQL 结构、实体、Mapper、业务服务和调用方。
- 字段类型、精度、空值、默认值、索引及表关联要一并评估。更新表结构时同时检查初始化、既有库升级、数据兼容、回滚与验证方式。
- 不通过直接修改业务数据绕过服务的业务约束；演示数据需核对数量、状态、金额、单号、库存流水和关联关系。
- 已按提供的结构形成[空测试库初始化文件](../database/init/README.md)并在隔离环境验证；既有库迁移与生产账号初始化需单独制定方案。
- 使用脱敏或虚构数据测试，不把实际客户、供应商、员工信息、账号凭据或含真实数据的数据库导出提交到仓库。

历史设计约定见 [数据库设计约定](../database/database-design-conventions.md)，模拟数据见 [模拟数据说明](../database/demo-data/README.md)。
