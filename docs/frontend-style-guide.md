# 启衡 ERP 前端界面风格规范

## 1. 整体风格

启衡 ERP 后续页面统一采用简洁、克制、清晰的后台管理风格。

页面重点不是装饰，而是让业务人员快速定位数据、筛选数据、执行操作。视觉上优先保证信息密度、表格可读性和操作层级清楚。

## 2. 操作按钮

列表页操作按钮默认采用浅色底色、低饱和边框和明确文字，不优先使用重色实底按钮。

推荐风格：
- 普通操作使用浅蓝或浅灰底色，文字颜色清晰，边框轻量
- 危险操作使用浅红底色和红色文字，不使用大面积红色实底
- 行内操作不放过多按钮，只保留高频操作
- 能批量处理的操作放在表格工具栏，不堆在每一行里
- 行内按钮不强制放图标，文字已经足够明确时删除图标

用户管理页当前标准：
- 行内只保留“编辑”和“角色绑定”
- “编辑”使用浅蓝操作风格，“角色绑定”使用浅黄色操作风格，用颜色区分两个同级但不同性质的行内动作
- “角色绑定”按钮当前颜色标准：文字 `#dbd400`，背景 `#f0f7c5`
- 用户管理表格的角色标签需要比普通标签更明显，采用浅蓝底、深蓝文字和较明显边框
- 批量启用、批量停用、重置密码、删除放在表格工具栏
- 删除按钮采用浅红色风格，后续危险操作参照这个搭配
- 新增按钮放在表格工具栏右侧操作区，不放在页面标题右侧，避免页面头部和列表操作分离
- 表格工具栏的操作按钮组保持右对齐，不要整体左移

角色管理页当前标准：
- 查询条件按 `sys_role` 字段拆分为角色编码、角色名称、状态，避免跨字段关键词混搜
- 角色表格中的权限码用摘要标签展示，点击“查看明细”弹出只读明细；摘要标签使用用户管理角色标签同款蓝色框
- “权限配置”属于高风险维护入口，行内按钮使用浅红色操作风格

## 3. 表格标签

表格里的角色、状态、是否类字段使用内容自适应的小标签。

要求：
- 角色标签宽度保持在约 `102px`，高度约 `32px`，字号 `13px`
- 其他标签宽度跟随文字内容，不做过宽的大框
- 标签文字垂直居中、水平居中
- 标签高度统一，避免同一张表内大小不一致
- 多个标签横向排列，空间不足时自然换行
- 部门、角色、状态、是否类字段默认居中显示；账号、时间等需要阅读上下文的字段可以左对齐
- 常规列表行高以 58px 左右为目标，避免表格显得松散

## 4. 分页

列表分页不要全部堆在右侧。

推荐布局：
- 数据总数放在分页区域左侧
- 每页条数选择放在页码控件左侧并保持贴近，页码控件居中，跳页控件单独靠右
- 分页区域保持低视觉权重，不抢表格主体注意力

## 5. 图标使用

图标只在以下场景使用：
- 顶部导航、侧边菜单等识别性入口
- 查询、新增、刷新等常见工具按钮
- 用户不容易仅靠文字判断含义的功能

以下场景优先不用图标：
- 表格行内的“编辑”“角色绑定”等含义明确的文字按钮
- 同一列中重复出现的高频操作按钮

## 6. 后续页面复用原则

产品、仓库、采购、销售等后续模块的列表页，默认复用用户管理页的结构：
- 页面标题和简短说明
- 指标概览
- 筛选区
- 表格工具栏
- 数据表格
- 左侧总数、中间分页
- 新增和编辑使用弹窗或抽屉
- 行内保留少量高频操作，批量操作放工具栏
