# 测试资料

本目录按测试类型组织入口，是否通过以具体版本、环境和运行记录为准。

- [后端测试](backend.md)：Maven 测试及依赖环境。

- [模拟数据检查](../database/demo-data/README.md)：数据规则与 Redis 编号同步。

浏览器测试截图默认输出到 `docs/testing/evidence/`，属于运行产物，不代表其他版本自动通过。测试账号、记录和截图应使用虚构或脱敏数据；不得包含真实凭据和个人信息。
