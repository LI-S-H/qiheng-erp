# 后端测试

后端测试在 `erp-server/` 执行：

```bash
mvn test
```

Maven 会根据模块配置运行测试阶段；具体测试是否需要 MySQL、Redis、MQ、模型服务或额外配置，应逐项查看测试代码和实际运行结果。不要因为构建成功就推断所有业务链路已验收。仅打包或部署时跳过测试的结果也不是测试通过。

需要真实服务和数据的检查使用独立测试库、测试账号与隔离基础设施。涉及订单、库存或其他写入的测试会改变目标环境；运行前先确认目标和数据隔离，并在完成后按团队约定处理夹具。

前后端和数据库的联合验证见 [四模块接口测试](integration/README.md)。
