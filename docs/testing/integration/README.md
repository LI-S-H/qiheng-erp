# 四模块接口集成测试

项目现有 PowerShell 脚本 `erp-server/scripts/run-four-module-api-it.ps1` 通过真实 HTTP 接口创建新的测试主数据，并覆盖采购入库、销售出库、采购退货、销售退货、库存锁定、幂等、部分执行和并发确认。详细参数以[脚本说明](../../../erp-server/scripts/README.md)及脚本本身为准。

运行前准备已启动的隔离后端、数据库及依赖服务，并通过环境变量提供测试账号。默认只允许本机环回地址；使用非环回测试环境需要显式启用脚本参数并确认目标。

脚本会新增带唯一前缀的测试记录，**不会自动清理**。请勿指向生产或真实业务数据库，结果和日志不得保留真实个人信息、密码或令牌。测试覆盖范围以脚本与实际运行结果为准。
