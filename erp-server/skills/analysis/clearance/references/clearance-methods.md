# 清仓方法

## 慢销判定口径

系统没有库龄和批次，只能用可验证的出库事实判断，三种口径按用户给的条件选：

| 口径 | 计算 | 说明 |
|---|---|---|
| 窗口内无出库 | 观察窗口内销售确认出库为 0 | 最保守，只需要出库记录 |
| 无出库间隔 | 今天 − 最近一次销售出库日 | 适合找长期没动过的货 |
| 覆盖天数 | 未预占 ÷ 日均出库 | 适合找压货但还在卖的货 |

- 阈值由用户给，没给就用"窗口内无出库"
- 三种口径结论可能不同，一次只选一种并写明
- 不能把覆盖天数说成库龄：覆盖天数是按当前速度推算的未来可卖天数，不是货物已经存放的时间

## 出库速度

```text
日均出库 = 窗口内销售确认出库量 ÷ 完整窗口天数
```

- 窗口必须是完整日历天数，缺数据的日子不能补 0
- 只统计销售确认出库，采购退货、销售退货入库、库存调整都不算市场需求
- 长期缺货会让速度偏低，先看窗口内库存是否长时间为 0，是的话标样本受限
- 日均出库为 0 时，覆盖天数不可估计，不输出无限大

## 可去化余量

```text
可去化余量 = max(0, 未预占 + 保护期可达在途 − 新增需求 − 期末保留)
```

- 未预占 = 库存 − 锁定，已经扣过锁定，不要再扣
- 新增需求只算尚未锁定的量；已提交销售单已经在锁定里，再减就重复了
- 可达在途只有预计到货日早于处置时点才计入
- 期末保留没给时用安全库存
- 结果按数量精度向下取整

保护期内如果用户同意取消一笔未收采购，先把它从在途里扣掉再重算，并说明这是另一个情景。

## 处置层级

行业常用的处置顺序，按回收效率从高到低：

```text
全价销售 → 降价促销 → 清仓甩卖 → 退供或批给清算商 → 捐赠 → 回收销毁
```

- 系统内能落地的只有：降价（改参考售价）、退供（采购退货单）、调拨（无单据，仅建议）、暂停补货
- 捐赠、报废、批给清算商在系统里没有对应单据，只能作为线下建议，不要描述成系统操作
- 每往下一层，回收率下降、流程成本上升，选择哪一层要看用户目标和可用参数

## 降价阶梯

零售常用的规则式降价，适合没有弹性数据的情况：

```text
触发条件：覆盖天数超过阈值，或无出库间隔超过阈值
阶梯示例：覆盖 90–120 天降 10%，120–180 天降 25%，超过 180 天降 40%
```

- 阶梯档位和降幅由用户确认，不默认套用上表
- 每档降价后重新观察一个周期，达不到目标再进下一档
- 没有价格实验历史时，不能承诺"降 x% 就能卖掉 y 件"
- 降价会影响后续所有销售定价，要提示用户这一点

### 反推目标

```text
目标日均 = 可去化余量 ÷ 目标清仓天数
需要提升倍数 = 目标日均 ÷ 当前日均
```

- 输出的是"速度要提到几倍"这个目标，不是降价幅度
- 用户给了具体降幅时，按新价格算收入情景，销量必须是假设值并注明
- 没有成本数据时只比较收入，不出利润结论

## 退供条件

退供要同时满足三件事，缺一件就只列为待确认：

1. 有原采购来源：该产品实际从某供应商采购入库过
2. 有可退量：已入库数量 − 已退货数量 > 0
3. 供应商接受：退货期限、折价率、运费承担已确认

```text
可退量 = 已入库数量 − 已退数量 − 已出库消耗
```

- 系统没有退货期限字段，期限必须由用户提供
- 已有退货单占用的数量不能重复退
- 退货折价直接减少回收金额，没有折价率时不给金额结论

## 调拨条件

调拨去化只在其他仓真的缺货时成立：

- 目标仓有未完成销售单或缺货缺口
- 目标仓净可用低于安全库存
- 运输时间可确认

不满足时不要为了"减少积压"硬调，只会在别的仓继续压着。

## 持有成本

判断降价还是继续持有，需要用户提供成本参数：

```text
持有成本 = 库存金额 × 资金成本率 × 持有月数 ÷ 12 + 仓储费率 × 库存金额
```

- 资金成本率和仓储费率系统里没有，必须由用户提供
- 缺参数时只做定性比较：越晚处置，资金占用和降价压力越大
- 没有成本参数时，不要算出"降价比持有更划算"这类结论

## 边界情况

| 情况 | 处理 |
|---|---|
| 窗口内无出库 | 给无出库间隔，覆盖天数标不可估计 |
| 从未出库 | 说明没有销售记录，不外推为无限积压 |
| 库存为 0 | 不是积压候选，直接排除 |
| 有缺货记录 | 速度偏低可能是缺货导致，标样本受限 |
| 参考采购价为空 | 库存金额标未知，不按 0 算 |
| 没有采购来源 | 退供不可行，写明原因 |
| 供应商未确认 | 退供列为待确认，不计入已执行 |
| 多个动作同时选 | 共用可去化余量上限，合计不能超 |
| 数量精度大于 1 | 各动作数量按精度取整，余量写清 |

## 复核

清仓不是一次决定，处置后要按周期复核：

- 降价后观察一个完整周期，看实际出库速度是否达到目标
- 未达目标再进下一档，不要一次降到底
- 退供执行后核对退货单状态和库存变化
- 调拨执行后确认两仓库存
- 所有动作执行后重算覆盖天数，判断是否还需要继续处置
