# 需求预测计算

## 能算出的结果

| 结果 | 需要的数据 | 算法 | 输出 |
|---|---|---|---|
| 日均需求 | 历史出库记录 | 按期间汇总平均 | 日均值 |
| 逐期预测 | 历史序列、预测期数 | 移动平均、指数平滑、Holt、Holt-Winters、Croston | 各期预测值 |
| 预测区间 | 残差或回测误差 | 残差标准差或分位数 | 上下界 |
| 季节因子 | 两个以上完整周期 | STL 或季节指数 | 每期季节系数 |
| 异常点 | 历史序列 | Z-score 或 IQR | 异常日期和数值 |
| 回测误差 | 历史序列、候选方法 | MAPE、MAE、RMSE、bias | 误差指标 |
| 基准对比 | 历史序列 | naive、seasonal naive、drift | 基准误差和优劣 |

## 算法选择

先跑基准，再选方法，最后用回测数据比较，不凭感觉选。

判断顺序：

1. 历史少于 3 到 4 个完整周期：返回数据不足，不给预测
2. 零值占比超过一半：Croston
3. 有两个以上完整季节周期且季节性明显：Holt-Winters 或 STL
4. 有持续趋势：Holt
5. 其余：移动平均或指数平滑
6. 选中方法必须好于对应的基准，否则退回基准方法并说明

方法公式、参数和历史长度要求见 `references/forecasting.md`。
异常检测、回测指标、基准定义和区间计算见 `references/validation.md`。

- 调用方式：`readSkillFile(skill="demand", path="references/forecasting.md")`
- 调用方式：`readSkillFile(skill="demand", path="references/validation.md")`
- 开始计算前先读取对应文件，不要按自己的口径心算

## 计算步骤

### 1. 数据准备

- 按业务口径还原数量：库内值除以 100
- 按粒度汇总到日、周或月，保持时间连续，缺失期补零并在结果中说明
- 记录历史区间、产品、仓库和单位

### 2. 异常检测

- 用 Z-score 或 IQR 标记异常点
- 异常点先单独列出，不要直接删除
- 用户确认前，同时给出含异常和剔除异常两种结果

### 3. 基准预测

先算三种基准：

- naive：用上一期实际值
- seasonal naive：用上一个同季节期的实际值
- drift：按历史平均变化量外推

基准误差是后面判断方法好坏的底线。

### 4. 候选方法回测

- 用滚动回测，不要用全量拟合后再预测同一段
- 至少留出 3 到 4 期做验证
- 比较各方法和基准的 MAPE、MAE、RMSE、bias
- 误差接近时选更简单、可解释的方法

### 5. 预测与区间

- 用选中的方法预测指定期数
- 区间基于回测残差估算，给出上下界
- 预测值不能为负，出现负值截断为零并说明

## 数据不足时

| 情况 | 返回 |
|---|---|
| 历史少于 3 期 | 数据不足，不预测 |
| 有趋势但不足 6 期 | 用移动平均，说明无法可靠判断趋势 |
| 有季节性但不足两个周期 | 用 Holt 或移动平均，说明未处理季节性 |
| 日期断档或粒度不一致 | 先要求补齐，不自行插值 |
| 零值占比过高但非间歇性 | 说明需求不连续，建议确认是否停售或断货 |

## 验证门

- 每个预测值必须来自实际计算，不能心算或估算
- 回测必须用滚动方式，不能用同一段数据既拟合又验证
- 选中方法的误差必须不劣于基准，否则退回基准
- MAPE 在真实值为零的期要跳过并说明，不能把零当分母
- 预测值不能为负
- 异常点处理必须记录：保留、剔除还是替换
- 历史长度和粒度必须写进结果

## 输出格式

按顺序返回，没有的写未提供：

1. 口径：仓库、产品、粒度、历史区间、单位
2. 数据情况：期数、零值比例、异常点数量和日期
3. 方法与选择依据：候选方法、回测结果、基准对比
4. 预测值：各期预测，带置信区间
5. 误差指标：MAPE、MAE、RMSE、bias
6. 限制：历史长度、异常点处理、是否处理季节性、无法覆盖的部分
