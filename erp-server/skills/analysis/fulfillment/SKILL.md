# 订单履约计算

## 能算出的结果

| 结果 | 需要的数据 | 算法 | 输出 |
|---|---|---|---|
| 待发量 | 订单数量、已出库数量 | 两者相减 | 按仓按产品汇总 |
| 履约缺口 | 待发量、库存、在途 | 待发 − 库存 − 可到在途 | 缺口数量 |
| 覆盖率 | 库存、在途、待发量 |（库存 + 可到在途）÷ 待发量 | 能否覆盖 |
| 风险订单 | 交付日、缺口 | 逐单判断 | 风险清单 |
| 最早断点 | 按交付日排序 | 第一个缺口日 | 日期 |
| 履约率 | 已出库订单 | 按期 ÷ 总数 | 历史表现 |
| 逾期量 | 逾期未发订单 | 合计待发量 | 逾期规模 |
| 锁定核对 | 锁定、待发量 | 两者比较 | 是否全部预占 |

## 算不出的结果

- 客户实际要求变更：系统没有变更记录
- 运输时效：系统没有发运和运输时间
- 产能和供应商交付能力：系统没有
- 拆单后的实际影响：需要业务判断

## 数据查询

开始取数前先调用 `readSkillFile` 读取 `references/fulfillment-queries.md`，里面是待发订单、库存、锁定、在途和历史履约的现成语句。

- 调用方式：`readSkillFile(skill="fulfillment", path="references/fulfillment-queries.md")`
- 判定口径和处置选项见 `references/fulfillment-methods.md`，一起读取
- 数量乘了 100，金额按分存储，计算和展示前除以 100
- 结果为空表示没有待发订单或没有在途，不是查询失败

## 指标计算

### 待发量

```text
待发量 = 订单数量 − 已出库数量
```

- 只算状态为已提交、已审批、部分出库的订单
- 草稿和已取消不计入
- 按仓库和产品分别汇总，不能只给全公司总数

### 履约缺口

```text
缺口 = max(0, 待发量 − 账面库存 − 交付日前可到的在途)
```

- 待发订单的货已经锁定，库存总量里包含它，所以用账面库存而不是可用库存
- 在途只有在预计到货日早于该批订单的交付日时才计入
- 缺口为 0 表示可以按时发

### 覆盖率

```text
覆盖率 =（库存 + 可到在途）÷ 待发量
```

- 覆盖率大于等于 1 表示够用
- 0.9 到 1 之间属于临界，要把到货波动考虑进去
- 小于 0.9 时列入风险

### 风险订单

逐单判断，条件按优先级：

1. 交付日已过且未发完：逾期
2. 缺口大于 0 且没有可到在途：高风险
3. 缺口大于 0 但在途能赶上：有条件风险
4. 覆盖率达到但库存低于安全库存：潜在风险

### 历史履约率

```text
履约率 = 按期完成出库的订单数 ÷ 已出库订单数
```

- 按期判断用出库确认时间与客户要求交付日比较
- 窗口和范围要和本次分析一致
- 履约率低说明系统性问题，不只是个别订单

### 锁定核对

- 待发订单的锁定量应该约等于待发量
- 锁定明显少于待发量时，说明有订单没有预占库存，存在超卖风险
- 锁定明显多于待发量时，说明有已取消或已完成订单没有释放锁定

## 计算步骤

### 第一步：汇总待发订单

- 按仓库、产品、客户汇总待发量
- 记录每单的交付日和状态
- 排除草稿和已取消

先按仓库汇总。范围超过一个仓库或 100 单时，只返回汇总和按仓风险分布，逐单明细等范围收敛后再查。

### 第二步：核对库存与锁定

- 查各仓账面库存和锁定
- 比较锁定量与待发量，判断预占是否完整

### 第三步：查在途

- 按仓库列出在途采购和到货日
- 只保留交付日之前能到的部分

### 第四步：算缺口和覆盖率

- 逐仓逐产品计算
- 标出缺口为 0 和大于 0 的
- 计算整体覆盖率

### 第五步：排风险清单

- 按逾期、高风险、有条件风险排序
- 每单给出缺口和交付日
- 找出最早断点日期

### 第六步：核对

- 待发量没有包含草稿和取消
- 缺口用的是账面库存，不是可用库存
- 在途到货日已与交付日比较
- 锁定核对结果已说明

## 数据不足时

- 没有交付日：按订单创建日加默认交期估计，并标注是估计
- 没有在途数据：缺口按无在途计算，会偏大
- 没有锁定数据：跳过硬核对，说明存在超卖风险但无法确认
- 没有历史出库：不给履约率，只给当前风险
- 仓库库存记录缺失：按该仓不铺此货处理，不当成 0 库存

## 验证门

- 待发量排除了草稿和取消
- 缺口用账面库存计算，没有重复扣锁定
- 在途只算交付日前能到的
- 风险订单有交付日和缺口
- 逾期订单单独列出
- 覆盖率和缺口口径一致

## 输出格式

按顺序返回，没有的写未提供：

1. 口径：仓库、客户、产品范围、截止日期
2. 待发汇总：按仓按产品的待发量
3. 供给：库存、锁定、在途
4. 缺口和覆盖率：逐仓结果
5. 风险订单：客户、产品、交付日、缺口、等级
6. 最早断点：日期和影响订单
7. 历史履约率：按期比例和样本
8. 处置建议：调拨、催采购、拆单、延期各能解决多少
9. 未知项与限制
