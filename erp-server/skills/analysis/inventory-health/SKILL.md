# 库存健康计算

## 能算出的结果

| 结果 | 需要的数据 | 算法 | 输出 |
|---|---|---|---|
| 周转率 | 出库数量、平均库存数量 | 出库数量 / 平均库存数量 | 次数 |
| 周转天数 | 周转率 | 期间天数 / 周转率 | 天数 |
| 最近入库天数 | 最近入库日期、库存 | 快照日期 − 最近入库日期 | 天数，估算 |
| ABC 分类 | 年度消耗金额 | 累计占比 80/15/5 | A/B/C |
| 呆滞占比 | 最近出库日期、库存 | 超阈值未出库的库存金额占比 | 比例和清单 |
| 零库存有需求 | 当前库存、期间出库记录 | 库存为零但期间有出库的产品 | 产品清单 |
| 安全线覆盖率 | 可用量、安全库存 | 可用量不低于安全线的产品占比 | 比例 |

## 算法与口径

- ABC 按年度消耗金额降序累计：累计 80% 为 A，接下来 15% 为 B，剩余 5% 为 C，阈值可由用户指定
- 周转率优先用数量法：出库数量除以平均库存数量；拿到入库单价时才用成本法，且同一报告不能混用
- 平均库存取期初期末均值，不取时点值
- 系统没有批次号：库龄只能用最近一次入库日期估算，输出必须标注估算
- 系统没有缺货记录，无法统计真实缺货率；用"零库存但期间有出库"的产品近似
- 期初库存没有历史快照，按期初 = 期末 − 期间入库 + 期间出库倒推；流水不完整时不计算周转率
- 呆滞阈值默认 90 天无出库，可由用户指定
- 数量按库内值除以 100 还原，金额和产品参考价都按分除以 100
- 公式和阈值参考见 `references/metrics.md`
- 调用方式：`readSkillFile(skill="inventory-health", path="references/metrics.md")`，开始计算前先读取，不要按自己的口径心算

## 计算步骤

1. 确定窗口：诊断期间和库存快照时点
2. 汇总出库：按产品和仓库汇总出库数量，有入库单价时一并汇总成本
3. 计算平均库存：期初和期末快照取均值
4. 计算周转率和最近入库天数
5. 做 ABC 分类
6. 找异常：呆滞、零库存有需求、超安全线
7. 汇总分维度结论

## 数据不足时

- 缺期初库存：只用期末快照，标注周转率不可算
- 缺出库成本：周转率按数量计算并注明口径
- 缺库存流水：期初无法倒推，周转率不可算
- 缺入库记录：最近入库天数无法计算，说明原因
- 缺安全库存：只给周转和结构，不判断缺货风险

## 验证门

- 周转率分子分母口径一致，都用成本或都用数量
- 平均库存用期初期末均值，不用时点值
- ABC 各档累计占比合计为 100%
- 呆滞清单里的"无出库"要确认是没需求还是没记录
- 数量还原和金额换算核对一次

## 输出格式

按顺序返回，没有的写未提供：

1. 口径：仓库、产品、窗口、金额口径
2. 总体：库存金额、数量、SKU 数
3. 周转：周转率、周转天数、与上期对比
4. 结构：ABC 各档金额和 SKU 占比
5. 最近入库天数：按产品列示，标注是估算
6. 异常清单：呆滞、零库存有需求、超安全线
7. 限制：缺失数据和假设
