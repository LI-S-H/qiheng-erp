# 库存策略计算

## 能算出的结果

| 结果 | 需要的数据 | 算法 | 输出 |
|---|---|---|---|
| 安全库存 | 日均需求、需求波动、交期 | max/min 法或服务水平法 | 数量 |
| 再订货点 | 日均需求、交期、安全库存 | 平均需求 × 交期 + 安全库存 | 数量 |
| 固定批量 | 年需求、订货成本、持有成本 | EOQ，再按 MOQ 和精度取整 | 数量 |
| 定期补货目标水位 | 日均需求、复核周期、交期、安全库存 | 日均 ×（周期 + 交期）+ 安全库存 | 数量 |
| 策略回测 | 历史需求、交期、参数 | 按历史序列模拟 | 缺货次数、平均库存 |
| 参数敏感性 | 参数变化幅度 | 逐档计算 | 服务水平与库存的对应 |

## 数据来源

| 参数 | 系统来源 | 说明 |
|---|---|---|
| 日均需求和波动 | 库存流水按商品汇总 | 按粒度和窗口统计 |
| 安全库存基线 | 产品档案 safety_stock_qty | 产品级，不是仓库级 |
| MOQ | 供应商产品档案 min_order_qty | 多个供应商时按实际采购供应商取 |
| 报价和有效期 | quoted_purchase_price、quote_valid_until | 过期报价只作参考 |
| 平均交期 | avg_delivery_days，或采购单实际到货日逐单计算 | 实际交期更可靠 |
| 订货成本、持有成本 | 系统没有 | EOQ 需要用户提供，缺了不算 |
| 包装步长 | 系统没有 | 需要供应商确认，缺了按数量精度取整并说明 |

## 算法选择

1. 有足够历史（至少 8 到 12 期）且能算出需求标准差：服务水平法
2. 只有观测到的最大最小值：max/min 法，并在结果中说明这是保守估计
3. 需求和交期都波动：用双波动公式；只有需求波动：用单波动公式
4. 间歇性需求：先用 Croston 估计需求，再按服务水平法定安全库存
5. 没有历史：不给参数，返回数据不足

公式、Z 值表和适用条件见 `references/inventory-policy.md`。

## 计算步骤

### 第一步：统计需求

- 按商品和仓库汇总历史需求，还原为业务数量
- 计算日均需求、日需求标准差、日最大需求
- 剔除异常点前先列出，不直接删除
- 趋势和季节性明显时，按同季节相位统计，不混用全年数据

### 第二步：统计交期

- 用实际到货日减下单日计算交期，不用承诺交期
- 计算平均交期、最长交期、交期标准差
- 交期记录少时，用最大观测值作保守估计，并说明样本不足

### 第三步：计算安全库存

单波动公式：

```text
SS = Z × σd × √L
```

双波动公式：

```text
SS = Z × √(L × σd² + avg_daily² × σL²)
```

max/min 法：

```text
SS = max_daily × max_lead − avg_daily × avg_lead
```

- Z 值由服务水平决定：90% 约 1.28，95% 约 1.65，99% 约 2.33
- 安全库存不能为负，出现负值时截断为零并说明

### 第四步：计算再订货点

```text
R = avg_daily × L + SS
```

- 有在途时，触发点可以扣掉在途量，但要在结果中说明
- 再订货点是最低触发线，不是目标库存

### 第五步：计算批量

再订货点模式：

```text
EOQ = √(2 × 年需求 × 每次订货成本 / 单位年持有成本)
Q = max(EOQ, MOQ) 按精度取整
```

定期补货模式：

```text
目标水位 S = avg_daily × (复核周期 + L) + SS
每次补货量 = S − 可用库存 − 在途
```

- 缺订货成本或持有成本时，EOQ 不计算，改为给出按覆盖天数估算的批量并说明依据

### 第六步：回测

- 用最近 6 到 12 期历史模拟这套参数
- 输出：缺货次数、缺货天数、平均库存、最大库存
- 与目标服务水平比较，偏差大时说明原因
- 不要用回测结果反过来过拟合参数，参数仍按公式计算

## 参数敏感性

给出至少三档服务水平的对比：

| 服务水平 | Z 值 | 安全库存 | 预估缺货天数 |
|---|---|---|---|
| 90% | 1.28 | | |
| 95% | 1.65 | | |
| 99% | 2.33 | | |

让用户看到提高服务水平的库存代价，由用户决定目标。

## 数据不足时

- 历史少于 8 期：不给标准差，改用 max/min 法并说明
- 缺实际到货日：用采购单承诺交期作情景，标注不可靠
- 缺订货成本或持有成本：EOQ 不计算，给按覆盖天数估算的批量
- 完全没有历史：返回数据不足，不给参数
- 新产品：按同类商品参数试运行，并标注需要观察

## 验证门

- 安全库存不小于 0
- 再订货点大于安全库存
- 交期用实际到货日计算，不用承诺日
- 需求统计和交期统计的窗口一致
- 回测结果与参数计算使用同一套历史
- 批量按 MOQ 和精度取整后不小于 MOQ
- 服务水平与 Z 值的对应关系写进结果

## 输出格式

按顺序返回，没有的写未提供：

1. 口径：商品范围、补货模式、需求窗口、交期窗口、服务水平
2. 需求统计：日均、标准差、最大日需求
3. 交期统计：平均、最长、标准差、样本数
4. 参数：安全库存、再订货点、批量或目标水位，以及计算依据
5. 敏感性：三档服务水平对应的库存和缺货
6. 回测：缺货次数、平均库存、与目标的偏差
7. 限制：数据不足、假设、需要复核的条件
