# 促销方法

## 基线

基线是"不做活动预计卖多少"，是估计值，不是查出来的事实。三种取法：

| 方法 | 计算 | 适用 |
|---|---|---|
| 去年同期 | 去年同期同窗口销量 | 有季节性、历史足够 |
| 移动平均 | 最近 3 到 6 个月月均 | 平稳品类 |
| 用户给定 | 用户直接给数 | 有业务判断或外部计划 |

- 窗口内缺货的月份要剔除或标注，否则基线偏低
- 有促销、清仓、断货的月份不能直接混进基线
- 输出必须写明用了哪个窗口和方法
- 基线销量为 0 时不计算增量率

## 增量与增量率

```text
增量销量 = 活动销量 − 基线销量
增量率 = 增量销量 ÷ 基线销量
```

- 活动销量是用户给定还是历史估计，要注明
- 增量销量可能为负，负值表示活动销量低于正常水平
- 增量率只在基线大于 0 时计算

## 单位贡献

```text
单位贡献 = 售价 − 单位成本 − 单位变动费
```

- 正常和活动分别计算，成本相同但售价和变动费可能不同
- 单位变动费是每卖一件新增的费用，如配送、平台佣金
- 已经被成本包含的费用不能重复扣
- 成本来源逐项标注：用户提供、财务提供、代理情景、缺失

## 增量贡献

```text
增量贡献 = 活动销量 × 活动单位贡献 − 基线销量 × 正常单位贡献 − 新增固定费
```

- 结果为正表示活动增利，为负表示减少贡献
- 活动销量是活动期总销量，包含原本就会卖出的部分；基线销量是它的对照，不能把活动销量当成额外增量再加一次
- 新增固定费是活动带来的净增固定成本，不是整场活动的总费用
- 单位贡献小于等于 0 时公式不适用，直接说明价格覆盖不了成本
- 成本缺失时不输出这个结果，只做收入情景

## 盈亏平衡销量

```text
盈亏平衡销量 =（基线销量 × 正常单位贡献 + 新增固定费）÷ 活动单位贡献
```

这个门槛不仅覆盖活动费，还要弥补降价带来的单位贡献下降。

### 持平与增利

```text
持平销量 = 按数量精度向上取整的盈亏平衡销量
增利销量 = 持平销量 + 一个精度单位
```

- 刚好等于盈亏平衡销量时，增量贡献为 0，是持平不是增利
- 判断正负用未取整的数值，不要先四舍五入再判断
- 数量精度为 0 时一个精度单位是 1 件；精度为 2 时是 0.01
- 活动单位贡献小于等于 0 时不要套除法，直接在可卖数量范围内试算

### 示例

```text
正常：售价 100，成本 60，变动费 5，销量 100
活动：售价 90，成本 60，变动费 5，销量 150
固定费：200

正常单位贡献 = 100 − 60 − 5 = 35
活动单位贡献 = 90 − 60 − 5 = 25
增量贡献 = 150 × 25 − 100 × 35 − 200 = 50
盈亏平衡销量 =（100 × 35 + 200）÷ 25 = 148
```

- 148 件只是持平，149 件才增利
- 需要比基线多卖 48% 才能覆盖降价和活动费

## 供给承接

```text
供给上限 = 活动期初可售 + 活动期内可到货
```

- 期初可售 = 库存 − 锁定
- 锁定已经包含未完成销售单的预占，不再重复扣减已承诺数量
- 可到货只有在活动期内能到货的在途才计入
- 多个活动共用库存时按活动分配，不能各自按全量报
- 供给上限低于增利销量时，说明按当前价格做不满量，差的多少要写清

若已承诺订单也参加活动价，不能重复计算：它们的销量包含在活动销量里，对应的收入也按活动价算。

## 毛利底线

```text
最低售价 = 单位成本 ÷（1 − 最低毛利率）
毛利率 =（售价 − 单位成本）÷ 售价
```

- 毛利率按售价口径，不含变动费和固定费，与贡献率不同
- 用户没给最低毛利率时不设默认值
- 活动价低于最低售价时标越线，并说明差多少
- 数量或价格精度会导致取整后略低于底线，要按精度向上取整后再判断

## 归因与复盘

没有对照组时，活动前后的销量差异不能直接归因给促销：

- 同期有未参加活动的同类商品，可以做简单对照
- 没有对照时只描述差异，说明可能受季节、缺货、竞品影响
- 活动期间同时有缺货时，销量增幅会被低估
- 活动期间有其他变化（涨价、换包装、渠道调整）时，不能归因给价格

```text
对照法增量 = 活动商品增量率 − 对照商品同期变化率
```

- 对照商品要同类、价格带接近、活动前销量水平接近
- 对照法仍然不是严格实验，输出时要注明

## 边界情况

| 情况 | 处理 |
|---|---|
| 没有成本数据 | 只做收入情景，明确未做利润结论 |
| 没有基线 | 用历史同期估计并标注，或请用户给定 |
| 基线为 0 | 不算增量率，只列销量和收入 |
| 活动销量未定 | 给增利门槛，让用户判断能否卖到 |
| 活动单位贡献小于等于 0 | 不套盈亏平衡公式，直接说明 |
| 供给不足 | 说明能卖多少、差多少、需要补多少货 |
| 越毛利底线 | 说明最低售价和差距 |
| 多个活动同期 | 共用供给上限，合计不能超 |
| 没有对照组 | 只描述差异，不给因果 |
| 成本用代理值 | 结论标注为代理情景，不能写实际利润 |

## 复核

活动结束后按周期复核：

- 实际销量与假设销量的差距
- 实际收入与预测收入的差距
- 供给是否成为瓶颈
- 活动是否带来后续价格敏感，客户是否在等下次降价
- 复盘结果用于修正下一次的基线方法和销量假设
