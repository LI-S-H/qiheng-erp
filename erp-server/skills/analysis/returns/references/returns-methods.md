# 退货分析方法

## 退货率口径

| 类型 | 分子 | 分母 |
|---|---|---|
| 采购退货率 | 采购退货数量 | 同期采购入库数量 |
| 销售退货率 | 销售退货数量 | 同期销售出库数量 |

- 两类分母不同，不能合并成一个"总退货率"
- 按金额计算时，分子用退货明细金额，分母用同期入库或出库金额，口径一致
- 窗口必须对齐：退货按退货单创建时间，入库按确认时间，出库按确认时间
- 分母为 0 时不输出比率，只输出退货量
- 退货率要结合样本量看，5 单以内的比率没有判断价值

## 原因编码

- `QUALITY` 是历史编码，读取时归一为 `QUALITY_ISSUE`
- `CUSTOMER_RETURN` 是历史销售退货编码，不在当前枚举内，保留原值并标注为历史编码
- 其他不在枚举内的值归入 `OTHER`
- 原因是人工填写，同一问题可能被填成不同编码，分组结论只作方向参考

## 集中度

```text
份额 = 该对象退货量 ÷ 退货总量
集中度 = Σ 份额²
```

- 可以用在供应商、产品、客户三个维度
- 集中度接近 1 说明退货集中在少数对象
- 判断"某家供应商问题突出"需要同时满足：集中度高、单量足够、退货原因指向质量问题
- 单次大批量退货会拉高集中度，先看笔数再看金额

## 趋势

```text
环比 = 本期退货量 ÷ 上期退货量 − 1
```

- 期长一致，按月或按季度
- 退货量上升要同时看采购量或销售量，业务规模扩大时退货绝对量上升是正常的
- 季节性产品要和去年同期比，不只看环比
- 原因分布的变化比总量变化更能说明问题

## 对库存和供应的影响

- 采购退货减少库存，可能让原本够用的库存转为缺货
- 销售退货增加库存，可能形成积压
- 判断影响时用退货数量对比当前库存，相对规模低于 5% 时影响有限
- 退货集中在某个仓库时，其他仓可能不受影响，不能按全公司结论推广

## 与质量评分的关系

- 供应商质量分来自入库质检的合格与不合格数量，不含退货
- 退货原因若大量是质量或破损，说明质检没有完全发现问题，质量分可能偏乐观
- 两者口径不同，不能直接相加或替代

## 边界情况

| 情况 | 处理 |
|---|---|
| 窗口内无退货 | 说明没有记录，不给比率 |
| 分母为 0 | 只给退货量 |
| 样本少于 5 单 | 只描述现象，不下结论 |
| 原因编码缺失 | 归入 OTHER 并说明 |
| 退货单未执行 | 申请量和执行量分开给 |
| 只有金额没有数量 | 按金额口径分析，说明数量缺失 |
| 采购退货和销售退货混问 | 分开算，再给各自结论 |

## 复核

- 退货处理结束后，核对执行状态和库存变化
- 供应商退货集中时，跟踪后续批次的质检结果
- 原因分布变化时，确认是否由填写习惯变化引起，而不是真实问题变化
